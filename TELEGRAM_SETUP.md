# Telegram ulash (Netlify)

Netlify → Site configuration → Environment variables:

| O'zgaruvchi | Qiymat |
|---|---|
| `TG_BOT_TOKEN` | BotFather bergan YANGI token (eskisi /revoke qilinsin) |
| `TG_CHAT_ID_LOR` | LOR shifokorlari guruhi ID |
| `TG_CHAT_ID_NURSE` | Hamshiralar guruhi ID |
| `TG_CHAT_ID_KASSA` | Kassirlar guruhi ID |
| `TG_CHAT_ID` | (ixtiyoriy) umumiy zaxira guruh |

Guruh ID topish: botni guruhga qo'shing, guruhga xabar yozing, saytda Telegram sahifasida «Guruh ID larini topish» ni bosing.
Keyin Deploys → Trigger deploy, so'ng «Sinov xabarini yuborish».
